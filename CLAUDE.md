# Квест-лист

Геймифицированный to-do: реальные задачи дают золото и факелы, на них герой прокачивается в roguelike-подземелье и играет в казино на игровую валюту. Владелец — Denys. Общаться с ним по-русски, коротко, по делу, спорить, если идея слабая.

Рабочий прототип уже есть: `reference/prototype-v1.html`. Это один HTML-файл, его можно открыть в браузере. В нём вся логика, баланс и стиль. **Задача — перенести его в нормальный проект и сделать красивее.** Ранняя игра (примерно первые 20 этажей) остаётся как в прототипе: эти числа проверены ботом (`reference/balance-bot.js`). Дальше игра масштабируется до 1000+ уровней — правила в `docs/PROGRESSION.md`. Старое сохранение не переносим: персонаж создаётся заново.

## Документы

- `docs/GAME_SPEC.md` — все правила и числа: экономика, бой, подземелье, казино, скины, формат сохранения.
- `docs/PROGRESSION.md` — масштаб до 1000+ уровней: множители, бесконечное снаряжение, перерождение, темп.
- `docs/DESIGN.md` — дизайн-система: тёмный люкс-минимализм с перламутром для интерфейса, яркая готика и фэнтези для игры.
- `docs/SELF_HOST.md` — GitHub Pages, PocketBase на компе, Tailscale Funnel, бэкапы.
- `docs/KICKOFF.md` — кто что делает при запуске; первое сообщение для Claude Code.
- `docs/ROADMAP.md` — этапы и критерии готовности.

## Стек (решения приняты, не пересматривать без сильной причины)

- **Vite + TypeScript (strict)**, пакетный менеджер **pnpm**.
- **React** для интерфейса (задачи, герой, казино, лобби), **Phaser 4** только для игрового окна подземелья (грузится лениво).
- **Игровая логика — чистые TS-модули без DOM и Phaser** (`src/core/`): экономика, генерация этажей, бой, казино. Phaser и React только рисуют состояние и шлют действия. Так логика тестируется и не зависит от движка.
- **Vitest** для логики и симуляции баланса. Линтер **oxlint** + **Prettier** (typescript-eslint не поддерживает TS 7).
- **PocketBase** (один бинарник) на домашнем компе владельца для входа и синхронизации сохранения. Сохранение — **журнал неизменяемых событий** (коллекция `events`) плюс снимок (`snapshots`); слияние — объединение по id события, ничего не теряется. Каждое действие идёт через чистый `apply(state, action) → {state, event}` в `src/core`.
- **PWA** (vite-plugin-pwa), офлайн-first: иконка на главном экране iPhone, сохранение сначала в IndexedDB, синхронизация, когда сервер доступен.
- **Деплой без домена и без оплаты:** публичный репо → GitHub Actions → **GitHub Pages** (интерфейс); PocketBase как сервис на компе, наружу только `/api` через **Tailscale Funnel**. Подробно в `docs/SELF_HOST.md`, порядок запуска в `docs/KICKOFF.md`.

## Структура

```
src/
  core/        # чистая логика: economy.ts, hero.ts, dungeon/ (gen, fov, combat, ai), casino.ts, save.ts, rng.ts
  game/        # Phaser: сцены, спрайты, анимации, свет, частицы
  ui/          # React: экраны Tasks, Dungeon (лобби + обёртка Phaser), Hero, Casino; компоненты
  sync/        # PocketBase-клиент, офлайн-очередь событий
  assets/      # спрайты, звуки, шрифты (лицензии в assets/LICENSES.md)
tests/         # vitest: экономика, генерация, бой, RTP казино, бот баланса
deploy/        # pb_migrations/, pb_hooks/, install-server.ps1 (автозапуск), backup.ps1
assets-inbox/  # скачанные паки ассетов (оригиналы), отсюда отбираем в src/assets
reference/     # прототип и бот: только для чтения
```

## Правила работы

- Сначала логика в `src/core` с тестами, потом UI. Каждое число из `GAME_SPEC.md` — именованная константа в `src/core/config.ts`.
- Генерация этажа и бой должны быть детерминированы от seed (`rng.ts`), чтобы баг можно было воспроизвести.
- Золото даётся только за задачи. Факелы за золото не покупаются. Эти два правила — ядро мотивации, не ломать.
- Казино — только игровая валюта и всегда с отрицательным матожиданием для игрока. RTP проверяется тестом.
- Ассеты только с понятной лицензией: CC0 или купленные. Каждый пак записывать в `assets/LICENSES.md`.
- Персонажи: взрослые, модельные, вытянутые пропорции, стильные наряды без откровенности.
- Большие числа показывать только через `formatBig` (`src/core/format.ts`).
- Графика в два слоя: в подземелье пиксельные спрайты (база + палитра + накладки), в интерфейсе — крупные рисованные портреты.
- Перед коммитом: `pnpm lint && pnpm typecheck && pnpm test && pnpm build`.
- Репозиторий публичный: секреты только в `.env` (в .gitignore) или GitHub Secrets. Пароли за владельца не придумывать и не печатать — он вводит их сам.

## Команды (после этапа 0)

```
pnpm dev        # фронт на localhost:5173
pnpm test       # vitest
pnpm sim        # бот баланса: 365 дней, печатает таблицу прогресса
pnpm build      # сборка в dist/
pnpm pb         # локальный PocketBase для разработки (127.0.0.1:8091; 8090 — боевой)
```
