# Запуск: кто что делает

## A. Подготовка — делает Denys (около 1 часа, один раз)

Сюда попадает только то, что требует твоих аккаунтов, денег, паролей или клика в браузере.

1. **Установи Claude Code** на комп и войди в аккаунт (инструкция: docs.claude.com → Claude Code).
2. **Аккаунты:** GitHub (если нет) и Tailscale (вход через GitHub или Google, тариф Personal бесплатный).
3. **Графика:** скачай и положи в папку `assets-inbox/` внутри проекта:
   - 0x72 «16x16 DungeonTileset II» (itch.io, CC0);
   - Kenney: «Tiny Dungeon» или «Roguelike/RPG pack» и «UI Pack» (kenney.nl, CC0);
   - по желанию: пак героев в аниме или фэнтези-стиле с анимациями (itch.io). Перед покупкой проверь лицензию: нужна коммерческая или «можно использовать в своих проектах»;
   - звуки по желанию: Kenney «RPG Audio» и «Interface Sounds».
4. **Сохранение из текущей версии:** Квест-лист → Герой → Сохранение → «Скопировать сохранение». Вставь в файл `reference/my-save.json`.
5. **Комп не должен засыпать от сети** (или смирись, что синхронизация ждёт, пока он проснётся).
6. **Распакуй пакет** в папку, например `~/code/questlist`, открой в ней терминал и запусти Claude Code.

## B. Инфраструктура — делает Claude Code (этап 0, одна сессия)

Ты только подтверждаешь входы в браузере, когда он попросит.

- Ставит нужное: git, Node LTS, pnpm, GitHub CLI, PocketBase, приложение Tailscale. Использует пакетный менеджер ОС и спрашивает подтверждение.
- `gh auth login` → **ты подтверждаешь в браузере.**
- Создаёт публичный репо `questlist`, первый коммит с docs и reference, каркас Vite + React + TS + Phaser + Vitest.
- Настраивает GitHub Actions и Pages, первый деплой заглушки.
- Ставит PocketBase как сервис, пишет миграцию `saves`, CORS для github.io.
  → **Ты сам** открываешь одноразовую ссылку установки PocketBase и создаёшь админа в браузере.
- `tailscale up` → **подтверждаешь в браузере;** Funnel → **одобряешь в админке Tailscale по ссылке.** Наружу открывается только `/api`.
- Скрипт ночного бэкапа в твою облачную папку.
- Прогоняет 5 проверок из `SELF_HOST.md`. **Ты проверяешь пункты 1–2 с телефона по мобильной сети.**

## C. Игра — делает Claude Code (этапы 1–5 из ROADMAP.md, несколько сессий)

Логика с тестами и ботом баланса → интерфейс в люкс-стиле с импортом `my-save.json` → подземелье на Phaser со спрайтами из `assets-inbox/` → вход и синхронизация → PWA и звуки. После каждого этапа ты играешь на телефоне и даёшь обратную связь.

## Первое сообщение в Claude Code (скопируй)

```
Прочитай CLAUDE.md и всё в docs/. Мы начинаем с этапа 0 из docs/ROADMAP.md по схеме docs/SELF_HOST.md
(GitHub Pages + PocketBase на этом компе + Tailscale Funnel, без домена).
Сначала определи мою ОС и покажи план этапа 0 по шагам: где нужен я (вход в браузере, пароль), а что сделаешь ты.
Пароли за меня не придумывай и не печатай. Публичный репо, без секретов в коде.
Начинай после моего «ок».
```

## Как понять, что старт удался

- После этапа 0: заглушка открывается по ссылке github.io с телефона, `/api/health` отвечает, push в main выкатывается сам.
- После этапа 2: ты закрываешь задачи в новой версии, и твой прогресс из прототипа на месте.
- После этапа 3: подземелье с анимированными спрайтами плавно идёт на iPhone.
