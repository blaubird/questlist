# Этапы

Каждый этап заканчивается рабочей версией, которую можно открыть на телефоне.

## 0. Каркас и инфраструктура
- Vite + React + TS strict, pnpm, oxlint и Prettier, Vitest, Phaser 4; `src/core` с RNG, `formatBig` и журналом событий; каркас интерфейса по `DESIGN.md`; PWA с иконкой и плашкой обновления.
- Публичный репо, GitHub Actions → GitHub Pages; PocketBase как сервис на компе с миграциями `events` и `snapshots`, закрытой регистрацией и защитой служебных эндпоинтов от запросов через Funnel; Tailscale Funnel только для `/api`; скрипт бэкапа. Порядок шагов — `docs/KICKOFF.md`.
- **Готово, когда:** выполнены 5 проверок из `docs/SELF_HOST.md`.

## 1. Ядро логики
- Перенести из прототипа в `src/core` экономику, героя, генерацию, обзор, бой, ИИ монстров, казино. Всё через `apply(state, action) → {state, event}`. Добавить механики масштаба из `PROGRESSION.md`.
- Тесты: награды и лимиты, серия, отмена; генерация (связность карты, портал достижим); точный RTP слотов 93,48%; свёртка журнала даёт то же состояние, что и прямое применение действий.
- `pnpm sim`: бот на 365 дней.
- **Готово, когда:** первые 21 день бот даёт картину, близкую к прототипу (этаж 15–17 к 10-му дню, около 20 к 15-му, 22–24 к 21-му; свитков меньше 15); дальше — темп из `PROGRESSION.md` (уровень ~1000 к третьему месяцу, без стен и без снежного кома), и ни в один день задачи не обесцениваются. ✓

## 2. Интерфейс
- Экраны «Задачи», «Герой», «Казино», лобби подземелья по `DESIGN.md`; боковое меню на компьютере; локальные шрифты; свои иконки вместо эмодзи.
- Ручной экспорт и импорт сохранения (JSON: снимок + журнал).
- Хранилище: журнал событий в IndexedDB (память — если браузер не даёт), синхронизация вкладок через BroadcastChannel, монотонное время событий, смена дня при открытом приложении, импорт = объединение журналов.
- **Готово, когда:** весь цикл задачи → золото и факелы → покупки → казино работает без подземелья.

## 3. Подземелье на Phaser
- Сцена: тайлсет по биомам, спрайт-анимации героя и монстров, плавное движение, камера, свет и факелы, частицы, цифры урона, мини-карта.
- Управление: тап-путь, зажатая крестовина, клавиши, вихрь, зелье.
- Графика — процедурная из прототипа (облики в подземелье совпадают с портретами интерфейса). Пиксельные CC0-тайлы стен и пола можно подставить позже: персонажей CC0-паков не хватает на 33 облика.
- **Готово, когда:** на iPhone 60 кадров/с без подтормаживаний, все механики из `GAME_SPEC.md` работают, бот проходит те же этажи через `core`.

## 4. Синхронизация
- Вход в PocketBase, синхронизация журнала событий (отправить свои, забрать чужие), офлайн-очередь, живое обновление через подписку PocketBase.
- Свёртка безопасна для офлайна на двух устройствах: награда за задачу одна, ресурсы не в минус, рекорды не откатываются (`tests/merge.test.ts`). Вход живёт 90 дней, лимит на создание событий поднят для первой выгрузки.
- Тесты: логика на поддельном сервере (`tests/sync.test.ts`), интеграция с настоящим PocketBase (`tests/pocketbase.it.test.ts`, запускается при заданном `PB_IT_URL`).
- **Готово, когда:** задача, закрытая на телефоне без сети, появляется на компьютере после того, как телефон снова в сети. ✓ (тест; на живых устройствах — за владельцем)
